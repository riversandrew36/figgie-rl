# Launch materials

Publish only after confirming the live demo and developer quickstart work.

## Announcement

I built Figgie Learning Lab: an open reinforcement-learning sandbox inspired by
Jane Street's Figgie.

Start in your browser: watch four scripted trading strategies, pause a round,
inspect initial-hand beliefs, and see exactly how trades and settlement affect
profit. Then move into Python to train a PPO policy, compare it with baselines,
and experiment with self-play.

The browser is a simplified strategy viewer; it doesn't run the trained policies.
The research environment and documented limitations are open source. I'd love
feedback on the learning experience and reproducible experiments.

Demo: https://riversandrew36.github.io/figgie-rl/
Source: https://github.com/riversandrew36/figgie-rl
Official Figgie: https://www.figgie.com/
